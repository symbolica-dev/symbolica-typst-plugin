# License text provenance

These upstream crate archives omit license files. The notice generator uses
the following texts from the repository commits recorded in their published
`.cargo_vcs_info.json` files:

- alloc-stdlib 0.2.4: [Dropbox license](https://github.com/dropbox/rust-alloc-no-stdlib/blob/ae42d22078b98549e987d2f03d12df7b984fde47/LICENSE).
- astro-float-macro 0.4.6 and astro-float-num 0.3.7: [MIT license](https://github.com/stencillogic/astro-float/blob/6c1c1fb5cd6c410a8aaa2b1d0c0aae08bacbfdf5/LICENSE).
- malachite-base, malachite-nz, and malachite-q 0.7.1:
  [GPL text](https://github.com/mhogrefe/malachite/blob/3f86b8e9a2eab40a62d8d7719415e80fd9a25190/COPYING)
  and [LGPL text](https://github.com/mhogrefe/malachite/blob/3f86b8e9a2eab40a62d8d7719415e80fd9a25190/COPYING.LESSER).
- smartstring 1.0.1: its published README supplies the copyright and MPL notice.
  The unmodified MPL 2.0 text is also distributed in colored 3.1.1's `LICENSE`.

Other license texts come directly from the versions pinned by `Cargo.lock`.
