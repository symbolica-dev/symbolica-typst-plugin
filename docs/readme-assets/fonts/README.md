# Banner fonts

These unmodified font files reproduce the approved Balanced banner:

- Space Grotesk 2.000 Regular and Bold for the title, subtitle, and tagline.
- JetBrains Mono 2.305 Regular for API names and code notes.

The banner uses a 32pt bold title, a 23.13pt regular subtitle, and a 12pt
regular tagline. Mathematical expressions retain their math font.

Space Grotesk comes from
[revision 03507d0](https://github.com/floriankarsten/space-grotesk/tree/03507d024a01282884232081fc6011c09ff4e849/fonts/ttf/static).
JetBrains Mono comes from
[revision 1937130](https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d/fonts/otf).
Both are distributed under the SIL Open Font License 1.1; the matching
copyright notices and licenses are included beside the fonts.

contains SVG outlines and does not need installed fonts.
