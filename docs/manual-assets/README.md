# Manual artwork

The manual uses the package logo at
[`symbolica/assets/symbolica-logo.svg`](../../symbolica/assets/symbolica-logo.svg).
See the [asset provenance](../../symbolica/assets/README.md) for its source and
licensing notice.

The manual palette follows the light theme in https://symbolica.io/styles.css:
brand `#0a9c7a`, strong brand `#087f64`, links `#0c7fc0`, text `#18222f`,
muted text `#445365`, borders `#d8e3ef`, and pale green `#e9f5ef`.
